# One Minute Quote Pressure V8 runbook

Candidate: `ONE_MINUTE_QUOTE_PRESSURE_V8`  
Account scope: DEMO only  
Timeframe scope: M1 only

V8 is mechanically runnable but intentionally order-locked until its frozen evidence gates pass. A failed gate retires this candidate without tuning it on the failed window. Do not create a promotion file by hand.

## Frozen files

The candidate manifest is `docs/analysis/2026-07-15-one-minute-quote-pressure-v8-manifest.json`. Verify it before any replay or promotion work:

```powershell
.\.venv\Scripts\python.exe .\scripts\freeze-one-minute-v8.py `
  --output .\docs\analysis\2026-07-15-one-minute-quote-pressure-v8-manifest.json `
  --verify
```

This verification fails if the detector, replay, lifecycle, broker code, launcher, tests, or design differs from the frozen SHA-256 set.

## Discovery

Collect each source once with the read-only collector. The commands do not invoke an MT5 mutation API.

```powershell
.\.venv\Scripts\python.exe -m cli.main one-minute-post-close-collect --start 2026-06-22T00:00:00Z --end 2026-06-29T00:00:00Z --output .\results\v8-fold-1.json
.\.venv\Scripts\python.exe -m cli.main one-minute-post-close-collect --start 2026-06-29T00:00:00Z --end 2026-07-06T00:00:00Z --output .\results\v8-fold-2.json
.\.venv\Scripts\python.exe -m cli.main one-minute-post-close-collect --start 2026-07-06T00:00:00Z --end 2026-07-13T00:00:00Z --output .\results\v8-fold-3.json
```

Run the frozen discovery gate:

```powershell
.\.venv\Scripts\python.exe -m cli.main one-minute-v8-screen `
  --stage DISCOVERY `
  --manifest .\docs\analysis\2026-07-15-one-minute-quote-pressure-v8-manifest.json `
  --fixture .\results\v8-fold-1.json `
  --fixture .\results\v8-fold-2.json `
  --fixture .\results\v8-fold-3.json `
  --output .\reports\v8-discovery.json
```

Stop if the report is not `PASS`.

## Promotion and DEMO progression

Create the initial 0.01-only promotion from the three passing reports:

```powershell
.\.venv\Scripts\python.exe -m cli.main one-minute-v8-promote `
  --manifest .\docs\analysis\2026-07-15-one-minute-quote-pressure-v8-manifest.json `
  --evidence-report .\reports\v8-discovery.json `
  --evidence-report .\reports\v8-held-out.json `
  --evidence-report .\reports\v8-prospective.json `
  --approved-volume-cap 0.01 `
  --output .\reports\v8-promotion-0.01.json
```

After at least 30 closed 0.01 trades across five completed, drained-flat sessions, audit the session directories with `one-minute-v8-audit-demo`. A passing audit can be supplied as the fourth evidence report to `one-minute-v8-promote --approved-volume-cap 1.0`. The audit rejects incomplete reconciliation, non-DEMO proof, nonzero safety failures, unverified flat shutdown, or live fill drift beyond the frozen one-spread allowance.

## Approved start command

This is the single supported order-capable start command. It refuses REAL, pre-existing exposure, stale ticks, missing stop-order capability, hash mismatch, unapproved volume, and a duplicate worker.

```powershell
.\scripts\start-one-minute-demo.ps1 `
  -CandidateManifest .\docs\analysis\2026-07-15-one-minute-quote-pressure-v8-manifest.json `
  -PromotionRecord .\reports\v8-promotion-0.01.json `
  -Volume 0.01 `
  -DurationHours 3 `
  -MaxSessionR 2 `
  -ShutdownGraceSeconds 120
```

Do not run that command until the referenced promotion exists and was generated by the promotion command. V8 never authorizes REAL trading. M15 and M30 remain outside this runbook.
